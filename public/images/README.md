# Photos (optional)

GYM BUDS ships with animated illustrations. To use real photos instead, drop images into this folder
with these exact names. Each one replaces its illustration automatically when the file exists.
If a file is missing, the illustration is shown, so nothing breaks.

| File          | Where it appears              | Suggested photo                         | Best size        |
|---------------|-------------------------------|-----------------------------------------|------------------|
| `hero.jpg`    | Landing page hero             | Person lifting dumbbells (portrait)     | 800 x 880 px     |
| `workouts.jpg`| "A week that makes sense"     | Person training, shoulder press or squat| 800 x 880 px     |
| `auth.jpg`    | Login / sign up side panel    | Gym or stretching scene (portrait)      | 800 x 880 px     |
| `cta.jpg`     | Background of final call out  | Wide gym shot (shown faded)             | 1600 x 800 px    |

Free sources with commercial-friendly licences: Unsplash (unsplash.com), Pexels (pexels.com), Pixabay (pixabay.com).
Check the licence on each photo, and keep file sizes under about 300 KB (use JPG or compress with squoosh.app) so the page stays fast.
